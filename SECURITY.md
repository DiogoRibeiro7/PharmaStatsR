# Security policy

Please report suspected vulnerabilities privately through GitHub's **Report a vulnerability** feature for this repository. If that feature is unavailable, contact the maintainer using the email in `DESCRIPTION`. Do not put sensitive details or patient data in a public issue.

The audit log helpers offer basic tamper evidence for a local CSV file. They do not provide access control, secure key storage, or a validated audit system. The package is not certified for regulated clinical decisions.
