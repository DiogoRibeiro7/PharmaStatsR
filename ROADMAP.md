# Roadmap

This file outlines planned milestones for PharmaTestR.

## Short Term
- Establish core statistical test functions.
- Provide documentation and examples for each function.

## Medium Term
- Add real-world pharmaceutical datasets for testing.
- Build wrappers for common regulatory compliance checks.

## Long Term
- Submit the package to CRAN once tests and documentation are stable.
- Expand test coverage and incorporate community feedback.
